# Table Tennis Room local trial

The public Warehouse tour's gold doorway selects **Table Tennis Room** by
ethan3111, https://superspl.at/scene/0d9e613b (CC BY 4.0). Its reciprocal doorway
returns to the Warehouse. The active catalog and publication closure omit Sunset;
historical source snapshots and legacy qualification tests remain available.

The downloaded SOG input has 1,244,410 Gaussians. PlayCanvas splat-transform 2.3.2
pairwise-merges this to 719,538, producing an 8,831,662-byte SOG. This keeps the
existing bounded packed accumulator allocation. Equal count is not a claim of
equal performance. The room uses its own exact asset/physics/transform/review
profile, checked before resources are read or allocated.

The original capture video and PLY were not supplied. A new strict SOG provenance
variant binds an inventory of the six downloaded source files. Original bytes
remain in the world source repository; the publisher verifies them and bundles
the inventory/review, runtime SOG and physics. It does not ship the original
14,955,138-byte source set. The shared contract was regenerated from owning source
commit `7acac33d27c917302622c9b4b745ad20399fe40e`; its source pin and the six-site
output-surface derivative were rechecked together. Older contract bundles reject
the new provenance variant.

Floor alignment comes from a robust fit to decoded points, followed by local
player-height visual inspection with floor/table wireframes. Scale is an assumed
gameplay scale. The floor, full table envelope and safety boundaries are authored
conservative proxies. They exclude adjacent gym space, outside access and stairs.
This is not a surveyed reconstruction or a physical-device qualification.

## Review gates

- PLAN: architect identified exact Sunset-only renderer, physics, readiness and
  owner pins, plus decoded-count limits. Decision: use a fixed coherent profile
  table, retain exact admission, and qualify new geometry rather than reuse Sunset
  data. An additive source-manifest provenance form was separately reviewed and
  implemented in the owning contract source; no invented capture hashes.
- NO-PROGRESS: two packaging attempts rejected a same-name retained CSS asset.
  Exact prior Git blob matched the new build (5,003 bytes); Windows checkout had
  5,004 bytes. Architect directed exact-byte staging from Git, preserving collision
  checks. No CSS or comparison normalization was introduced as a workaround.
- COMPLETION: recorded after the packaged browser checks and final review.
