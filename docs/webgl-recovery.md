# WebGL compatibility recovery

The 18 October Mac source stage included an established Three.js WebGL2 compatibility renderer absent from this checkout. On 23 October, 408 source files were recovered read-only to an operator evidence folder with per-file SHA256 provenance. The source stage has no Git metadata; it is a candidate implementation, not a demonstrated exact reconstruction of the served bundle. Its federation module matches the Mac guest3 staged server source.

This integration reuses the backend initializer and federated transition boundary. It does not import the two hard-coded installed world recipes or miniature pose-panel previews. Both backends now render the original customisable Rocketbox man and woman, with the original AvatarChooser and personal colours. The restored electrical rim comes from the existing portal branch. The finite crossing particles are new presentation tied to the existing authority transition, rather than a claimed exact recovery of an older animation. Both repository backends use the validated content loader, native Player and Colliders, common semantic portal transforms and one authority membership ledger. Worlds cannot provide executable rendering callbacks.

The recovered package declares MIT and Three.js 0.180. Existing ElseMesh licence and bundled Three.js notices continue to apply. No private operator configuration or signing key belongs in source or a world repository.
