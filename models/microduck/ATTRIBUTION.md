# Microduck geometry and motion
Original geometry: **Pollen Robotics**, https://github.com/pollen-robotics/microduck_rl
Original model files and converted/decimated geometry: **CC BY-NC-SA 4.0**,

This asset is separate from the application code's MIT license.

Adaptation: STL/MJCF to articulated glTF; rigid joint nodes and original RGBA colors retained; rough PBR materials; uniform 25 cm display scaling and default ground alignment; realtime triangle decimation; CPU MuJoCo official-policy response baked to seven clips. Horizontal root translation and yaw removed for world navigation. No generated substitute geometry.
