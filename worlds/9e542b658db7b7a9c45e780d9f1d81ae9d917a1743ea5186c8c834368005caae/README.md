# Neon Shift

Original explorable cyberpunk arcade city. A fixed 192 m square floor at y=0 supports a connected walking street network around 80 permanent solid 10 x 10 x 3 m building ground floors. Their authoritative lot inventory is shared with the installed renderer. Changing towers remain above those same lots, so the minute-by-minute visual changes never move a street, doorway or collision boundary. Ten-metre-high solid outer boundaries have inner faces at x/z=±96. There is no inner plaza fence.

Spawn [0,0,14], return doorway [0,1.8,18] and the clear central square stay fixed. The authored environment is 21:00 with rain. Original world and region identities are preserved. Old immutable snapshots remain available for recovery.

All authored scene content is original, MIT licensed, with no external assets or endpoints. Importing this world grants no runtime authority. CPU clearance and street connectivity checks are separate from browser or physical-device acceptance.
