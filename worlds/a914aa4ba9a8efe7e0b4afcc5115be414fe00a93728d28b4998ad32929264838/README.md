# Neon Shift

Original cyberpunk arcade world with a fixed 48 m square safe plaza, flat ground at y=0, 10 m tall solid perimeter walls and a reciprocal Warehouse doorway. Spawn and portal egress remain fixed while the installed game changes its visual city beyond the fenced boundary once per minute. The dynamic city is a bounded renderer effect, not mutable collision geometry or downloaded executable content.

All authored scene content is original, MIT licensed, with no external assets or network endpoints. Importing this world grants no runtime authority. CPU source clearance is verified separately from browser and physical-device acceptance.
